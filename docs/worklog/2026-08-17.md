## 五、WER 分桶分析（骨架 best.pt，dev/test）

- `scripts/analyze/wer_buckets.py`：按 **句子长度 / 手语者 / 词频** 三桶细粒度定位错误，词级 DP 对齐（match/sub/del/ins），输出 markdown 表格 + `reports/wer_buckets/results.json` + 柱状图 PNG（matplotlib 中文字体已修：Microsoft YaHei）
- 单元测试 12 个（align_words 回溯、桶边界、聚合口径）；全量 **164 passed**
- 关键结论（dev 489 段 WER 0.762 / test 485 段 0.757，beam=5）：
  1. **删除错误绝对主导**：dev del=690 vs sub=277 vs ins=12；test del=615 vs sub=304——模型**严重欠预测**：ref 均长 4.5-5.1 词，hyp 均长仅 2.1-2.4 词；34% 样本预测 ≤1 词，4-5% 空预测
  2. **词频长尾效应显著**：高频(≥50)词错误率 54% → 中频(20-49) 78% → 低频(5-19) 94% → 极低频(1-4) 99.5%（train 词表 3836 词中 2515 词仅出现 1-2 次）——模型只学会高频词
  3. **句子长度影响温和**：短句(≤3) 0.74 vs 超长句(≥8) 0.83，但各桶差距不大
  4. **手语者差异**：dev E/G 最佳(0.64-0.66)、I/H 最差(0.87-0.95，样本仅 9)；test J/L 最佳(0.65-0.68)——样本量小，结论待融合模型复测
  5. **句准确率近乎 0**（dev 0.2%）：WER 0.76 下整句全对概率极低，属正常
- 优化方向（供融合训练后对比）：欠预测 → 解码长度偏置/blank 偏好调整；长尾 → 数据扩充（CSL-Daily）或词频加权
