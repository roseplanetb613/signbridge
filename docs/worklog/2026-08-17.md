## 一、三流融合模型：FusionSTGCNCTC（步骤 1 ✅）

- `models/stgcn_fusion.py`：**hand 骨架（STGCNBlock 9 层）+ pose 姿态（4 层浅配置）+ ROI 手部图像（ResNet18 ImageNet 预训练）** → 1024 维融合 → 帧级 CTC 头
  - hand/pose 流：blocks → 节点均值 → (N, C, T'=32)
  - ROI 流：逐帧 ResNet18 → 时间下采样 ×2 → (N, 512, T')
  - 输出 `(N, T', K+1)`；`log_probs` / `decode` / `beam_decode` 与 STGCNCTC 兼容
- 单元测试 7 个（三流前向/CTC 反向全参数梯度/ROI 尺寸校验/T 对齐校验/自定义配置）
- 实现中排坑：ROI 时间维 np.tile 广播错误、NHWC/NCHW 转换、pose 流下采样对齐（T'=64→32）、Conv2d 3/4 维输入（unsqueeze）
- 全量测试 152 passed；导出顶层 API；commit：9544ff9 / 220762e / c8f030c
