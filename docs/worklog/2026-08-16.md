## 下午补充：小手/远端识别优化实验（用户反馈驱动）

### 背景
用户摄像头实测反馈：双手在摄像头远端识别效果待提高。同时 CE-CSL 小手样本
（train-00713，bbox ≈6100px）检测率仅 21-27%。

### 实验迭代（测量驱动的三版方案）

| 版本 | 方案 | 结果 |
| --- | --- | --- |
| v1 | ROI 放大**关键点精化**（全图检测 → 裁剪放大 → 第二遍重检测，失败回退） | ❌ 检测率不变（精化不改变能否检测到）；精度/置信度无收益甚至略降 |
| v2 | **两级候选检测**（低阈值 0.15 找回漏检 → ROI 放大 → 正常阈值确认，**确认失败丢弃**） | ⚠️ 精度大增（帧间位移 0.028→0.009，3 倍稳定）但**检测率反降**（确认失败丢弃真手候选） |
| v3（定型） | 两级候选检测 + **确认失败回退候选** | ✅ 检测率提升 + 正常样本零劣化 |

### v3 最终实测（refine_roi=True vs 关闭）

| 视频 | 检测率 | 置信度 | 帧间位移 |
| --- | --- | --- | --- |
| train-04468（单手手语） | 36% → **47% (+11%)** | 0.918→0.878 | 持平 |
| train-00713（小手 6100px） | 27% → **30% (+2%)** | 0.825→0.813 | 略降（回退帧拉低） |
| train-00001（正常） | 100% → 100% | 0.982→0.985 | 持平 |

### 结论

- **两级候选检测有效**：低阈值找回漏检（+2%~+11%），确认成功帧关键点精度显著提升
- **代价**：确认失败回退的低置信度帧会略拉低平均置信度/稳定性——可接受（漏检是主要矛盾）
- 待摄像头实测确认主观效果；剩余改进空间：候选 bbox 质量（margin 调优）、确认阈值分级

- 单元测试 5 个（两级语义/回退/无候选/单级不变量/双 landmarker）

## 下午补充二：handedness 标签抖动分析与防抖（用户反馈驱动）

### 背景
用户摄像头实测：左手摆出奇怪姿势时标签偶发跳变成右手。录制 654 帧
（含双人场景：前方正常手 + 后方小手测试），分析发现 43 次跳变事件。

### 根因
MediaPipe 对某些手形（旋转/手背角度大）左右手判定置信度接近，
每帧输出在 Left/Right 间随机漂移——**同一轨迹数百帧连续、位置不变，
确属同一只手的标签误判**，非换手。

### 方案：handedness 时序防抖（滞后切换）

`HandSequenceBuffer(handedness_debounce=5)`：判定相反需连续 ≥5 帧才切换标签；
0 关闭。新增参数默认 5，track 增加 flip_count 状态，新建轨迹无防抖（无历史）。

### 录制回放验证（detections.npz 重建流，双人场景）

| 指标 | 关闭防抖 | 开启(=5) |
| --- | --- | --- |
| 标签翻转总数 | 28 | **2（-93%）** |
| 轨迹 1（327 帧主手） | 4 | 0 |
| 轨迹 6/7（后方小手） | 4 / 8 | 0 / 1 |
| 轨迹 5（21 帧短轨迹） | 1 | 0（真实切换被保留） |

剩余 2 次翻转均为 ≥5 帧持续相反判定（真实换手/长时间姿势）——防抖设计边界，合理。

### 交付

- `handedness_debounce` 参数 + track.flip_count 滞后逻辑
- 单元测试 4 个（短抖动抑制/真实切换/0 关闭/双手独立）
- `scripts/record_camera.py`（录制：raw/overlay/detections.npz，支持 --preview）
- `scripts/analyze_handedness.py`（跳变事件分析：轨迹关联 + 手形特征距离）
- `scripts/replay_handedness_debounce.py`（防抖回放对比）
- 全量测试 121 passed；commit：f043b29 / b1c3152 / a5cf86b

### 7. 调研：Google 手势识别模型与论文

- [MediaPipe Hands](https://ar5iv.labs.arxiv.org/html/2006.10214#1)：两阶段
  （palm detection → ROI landmark refinement）+ 可学习 ROI 对齐
