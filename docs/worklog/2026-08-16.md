### 2. CE-CSL 真实数据集分析

- 结构：`label/*.csv`（UTF-8）+ `video/{train,dev,test}/{A..L}/*.mp4`
- 规模：train 4973 / dev 515 / test 500 句，1080p 30fps，4.8~7.2 秒/句
- **12 位手语者（A-L）**，官方 split 已随机混合（非按人划分）
- 性质：**连续手语句子**（Gloss 斜杠分隔词序列，无帧级时间戳），词汇约 3000+
- 手部检测实测：train-00001 前 60 帧 100% 检出

### 3. 真实数据链路验证

- `scripts/verify_dataset_pipeline.py`：视频 → 检测 → 缓冲 → 双手分块 → 腕点归一化张量 → ST-GCN 前向全链路跑通
- 发现并解决 **handedness 不可靠**问题（双手同侧误判）：采用**方案 B 分块**（handedness 优先，冲突时按画面 x 位置：左侧→块 0）
- 随机 10 视频 → 8/10 成功；诊断两个失败视频：1 个为**单手手语**（全程无双手同帧）、1 个为**小手样本**（bbox ≈6100px）

### 4. 批量验证管线优化（`verify_dataset_batch.py`）

- **段切分**：连续有手帧 ≥9 帧成段，gap ≤2 帧合并（容忍偶发漏检）
- **单手零填充**：单手帧手入块 0、块 1 零填充（兼容单手手语视频）
- **质量标记**：检测率 <30% → `LOW_DETECTION`；无段 → `NO_SEGMENT`
- **阈值可调**：`--conf 0.3`（小手样本检测率 21%→27%）
- 优化后随机 10 视频 **10/10 成功**；随机 20 视频（新 seed）**20/20 成功**，累计 30/30
- 段长 20~256 帧；手 bbox 5100~27600px（手语者间差异 5.4 倍）

### 5. Qt 特征提取可视化（`qt_demo.py` 增强）

## 三、遗留问题

### ⚠️ 双手在摄像头远端识别效果待提高（用户实测反馈）

- 现象：手离摄像头较远时（手部小），识别/跟踪效果下降
- 与 CE-CSL 小手样本（bbox ≈6100px）问题同源——MediaPipe 对小手部检测能力有限
- 候选优化方向（待评估）：
  1. **ROI 放大**：检测到手部包围盒后裁剪放大再二次提取关键点（对小手提精度）
  2. 降低 `min_detection_confidence`（已有 0.3 边际收益）
  3. 追踪阶段用上一帧 ROI 引导检测（利用时序上下文）
  4. 提高输入分辨率（摄像头支持时）
