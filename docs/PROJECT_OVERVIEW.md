# SignBridge — 项目一页纸（速览）

> 中文连续手语识别：从视频到词序列的完整深度学习系统，含数据管线、模型族、训练/解码框架与严谨的对照实验。

---

## 一句话

**基于 MediaPipe 关键点 + 时空图卷积（ST-GCN）+ CTC 的连续手语识别系统**，在 CE-CSL 公开数据集（5988 视频 / 12 手语者 / 3836 词汇 / 复杂背景）上从零构建全链路，骨架基线 dev WER **0.740**，并通过 6 组对照实验收敛"骨架模态信息量上限"结论。

## 核心数字

| 指标 | 值 |
|---|---|
| 骨架 baseline（60 epochs） | **dev WER 0.740** |
| 三模态融合（hand+pose+RGB，13 epochs 中断） | 0.8855 |
| 解码优化（长度偏置） | WER 0.762 → **0.749**（del -23%） |
| BLEU-1 解码侧极限（bonus=5） | 0.18 → **0.36** |
| 测试 | **195 passed** |

## 技术栈

Python · PyTorch · MediaPipe · OpenCV · NumPy · tqdm · matplotlib · PySide6（演示层）

## 三个最值得讲的实验（都是"证伪"类，展示科学方法）

1. **词表口径实验**：全词表（3836 词）比 min_count=3（1321 词）**更差**（0.808 vs 0.753）——证明"长尾问题"不是词表过滤造成的，否定常见补救路径。
2. **嵌入头实验**：将分类头替换为"特征投影 + 词嵌入表"（logits=f@Eᵀ），假设低频词从高频词"梯度溢出"——30/60 epochs 与 one-hot 完全持平（极低频词错误率 99.09% 分毫未动），**假设被严谨证伪**，避免了错误方向继续投入。
3. **模态消融**：三流融合模型输入遮挡实验——去掉 RGB 流 WER +0.26，去掉 hand 流无变化 → RGB 是信息主力；骨架模态三个独立架构（one-hot/嵌入头/时频双分支）全部收敛 0.74±0.01 = **模态信息量上限**，据此把资源转向 RGB 路线。

## 工程亮点

- **解码优化**：前缀束搜索 + 长度偏置（缓解 CTC 欠预测）；logits 缓存实现解码网格秒级扫描（beam×bonus×LM 全组合）
- **评估体系**：WER / 句准确率 / BLEU-1~4 / 三桶分析（句长·手语者·词频）+ S/D/I 词级对齐
- **Windows 深坑排障**（沉淀 Postmortem 文档）：
  - numpy NpzFile 无缓存 → 列表推导重复解压 = 37 分钟卡死 → 先取引用修复至 0.5s
  - 蒸馏 loss（KL）对 ref 分支梯度在极端 logits 下 NaN → ref detach 修复（符合蒸馏语义）
- 断点续跑（权重/优化器/调度器全恢复）、batch 级断点、tqdm 进度条
